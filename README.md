# LUPA Saúde

Fundação técnica do projeto Hack Brasil 2026 — trilha Saúde & Bem-estar.

Este repositório foi criado durante o período permitido pelo regulamento. A Etapa 1 contém a estrutura Next.js/TypeScript, páginas responsivas, componentes shadcn/ui, testes e a API GET /api/health. Ainda não há Supabase configurado nem deploy.

Veja `docs/STATUS.md` e `docs/ARCHITECTURE.md` para limites da implementação. O LUPA não realiza diagnósticos ou prescrições individuais.
